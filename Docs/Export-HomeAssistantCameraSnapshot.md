# Export-HomeAssistantCameraSnapshot
## SYNOPSIS
Exports one bounded camera snapshot through an atomic local-file replacement.

## SYNTAX
### __AllParameterSets
```powershell
Export-HomeAssistantCameraSnapshot [-EntityId] <string> [-Path] <string> [-Width <Int32>] [-Height <Int32>] [-Force] [-Connection <HomeAssistantConnection>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Exports one bounded camera snapshot through an atomic local-file replacement.

## EXAMPLES

### EXAMPLE 1
```powershell
Export-HomeAssistantCameraSnapshot camera.front ./front.jpg -Width 1280 -Height 720
```
