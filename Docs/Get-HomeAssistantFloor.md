# Get-HomeAssistantFloor
## SYNOPSIS
Lists Home Assistant floors with their joined areas, devices, and entities.

## SYNTAX
### __AllParameterSets
```powershell
Get-HomeAssistantFloor [[-Floor] <string>] [-Connection <HomeAssistantConnection>] [<CommonParameters>]
```

## DESCRIPTION
Lists Home Assistant floors with their joined areas, devices, and entities.

## EXAMPLES

### EXAMPLE 1
