# Remove-HomeAssistantCalendarEvent
## SYNOPSIS
Deletes a Home Assistant calendar event or recurring occurrence.

## SYNTAX
### __AllParameterSets
```powershell
Remove-HomeAssistantCalendarEvent [-EntityId] <string> [-Uid] <string> [-RecurrenceId <string>] [-RecurrenceRange <string>] [-Connection <HomeAssistantConnection>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Deletes a Home Assistant calendar event or recurring occurrence.

## EXAMPLES

### EXAMPLE 1
```powershell
Remove-HomeAssistantCalendarEvent -EntityId calendar.home -Uid event-1 -WhatIf
```
